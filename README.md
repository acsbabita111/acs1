# Applied Computer School™ — acs1.in Institutional Homepage v1

Purpose:
- acs1.in = Applied Computer School™ institutional website for offline & blended vocational training.
- acslearn.com = free online learning platform.
- ffgpmt.org = parent Trust/institutional history.
- acsaarthi.com = professional driver skills & mobility workforce initiative.
- acs-aidigitalmaster.org = specialised digital-learning programme.

Deployment:
1. Upload all files in this folder to the GitHub Pages repository for acs1.in.
2. Keep CNAME exactly as acs1.in.
3. In GitHub Settings → Pages, publish from the main branch/root.
4. Point GoDaddy DNS to GitHub Pages.
5. Enable HTTPS after DNS resolves.
6. Test desktop and mobile before public promotion.
